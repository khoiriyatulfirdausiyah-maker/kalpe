# Kalkulator HPP Android

Versi Android dari Kalkulator HPP Picnic.

## Fitur
- Buat dan simpan banyak menu
- Bahan baku + jumlah + satuan + harga/satuan
- Biaya kemasan, tenaga kerja, gas/listrik/lainnya
- HPP per porsi
- Target profit dan saran harga jual
- Semua menu dapat dibuka, diedit, dan dihapus
- Import JSON dari penyimpanan Android
- Export JSON ke folder Download/KalkulatorHPP
- Data utama disimpan lokal di perangkat

## Cara build APK lewat GitHub
1. Buat repository GitHub baru.
2. Upload semua isi folder project ini ke repository, bukan folder luarnya saja.
3. Commit ke branch `main`.
4. Buka tab **Actions**.
5. Pilih workflow **Build APK**.
6. Tunggu sampai status hijau / Success.
7. Buka hasil workflow lalu download artifact **Kalkulator-HPP-APK**.
8. Ekstrak ZIP artifact tersebut dan install `app-debug.apk`.
